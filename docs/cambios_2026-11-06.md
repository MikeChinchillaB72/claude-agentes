# Cambios del 2026-11-06

## Qué se hizo

Miguel fijó 8 reglas de trabajo y pidió revisar las reglas y premisas de TeloHago
para quedarse con las que aplican. Se adoptaron todas las propuestas (decisión de
Miguel, 12:15 UTC). Quedan en [REGLAS.md](REGLAS.md) como M1–M8 y T1–T16.

Para que las reglas no dependan de que alguien se acuerde (T1), se hizo:

1. **Configuración fuera del código (M7).** El modelo, el nivel de registro, el
   sandbox, los patrones de datos personales y todo lo de cada agente
   (instrucciones, herramientas, límites, subagentes, datos de prueba) pasó a
   `config/`. Lo lee un solo módulo, `agentes/configuracion.py`, que falla con un
   mensaje claro si falta una clave. La plantilla y los tres ejemplos ahora solo
   cargan su archivo. Las claves están en [CONFIGURACION.md](CONFIGURACION.md).
2. **Filtro único de datos personales (T13)** en los registros:
   `FiltroDatosPersonales`, con los patrones en `config/agentes.toml`.
3. **Ocho redes** en `redes/`, ejecutables con `python -m redes`: `secretos`,
   `silencios`, `literales`, `docstrings`, `vocabulario`, `generados`,
   `pendientes` y `docs`. Solo usan la biblioteca estándar.
4. **Cada red se prueba rompiéndola a propósito (T2)** en `tests/test_redes.py`.
5. **Tres puntos de ejecución:** hook `PreToolUse` de Claude Code que deniega el
   commit si una red falla (`onFailure: "block"`, para que un hook roto también
   bloquee), `.pre-commit-config.yaml` para commits a mano (gitleaks + redes) y CI.
6. **Documentación:** REGLAS, CONFIGURACION, la puerta `docs/README.md`,
   pendientes, hecho y esta bitácora. CLAUDE.md y el README raíz las enlazan.

  mandaba siempre sobre `config/agentes.toml`.
